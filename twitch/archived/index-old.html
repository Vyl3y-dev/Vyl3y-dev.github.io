🐾 About VyleyBot

VyleyBot is my custom Twitch companion bot, built to make chat more interactive while handling useful stream functions behind the scenes. It started as a small personal bot and has gradually grown into a collection of commands, integrations, games, chat utilities, and questionable ideas.

🧩 What Can VyleyBot Do?

  • Chat and utility commands
  • Spotify playback and queue interaction
  • League of Legends information
  • Custom Kotki currency system [IN DEVELOPMENT]
  • Stream games and interactive commands [SEMI IN DEVELOPMENT]
  • Shoutouts and social commands
  • Personality and ambient chat responses [IN DEVELOPMENT]
Some systems are still actively being developed and may change over time.

🔧 How it Works

When you open an app:

  1. script.js fetches its .html file from /apps/.
  2. Linked styles (.css) and scripts (.js) are dynamically loaded.
  3. Each app runs in its own sandboxed window.
Windows can be dragged, minimized, and later made resizable.

🎨 Design Philosophy

“Form follows function — but fun follows form.”

I believe tools should not only work well, but also feel delightful to use. That’s why this site merges aesthetics from:

  • Classic operating systems
  • Early web apps and pixel UIs
  • Modern flexibility and motion

📱 Tech Stack

  • Frontend: HTML, CSS, Vanilla JS
  • Backend (local dev): Python simple server
  • Version Control: Git + GitHub
  • Deployment: GitHub Pages
  • Planned Features: Local storage for app state, draggable/resizable windows, custom boot screen.
