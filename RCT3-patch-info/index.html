🎢 RCT3 Compatibility Helper

A small utility for RollerCoaster Tycoon 3: Complete Edition players affected by compatibility problems introduced by the March 2026 Steam update.

Download Latest Release View on GitHub

What does it do?

RCT3 Compatibility Helper detects your Steam installation and checks which version of RCT3.exe is installed.

If an affected version is detected, the helper can:

  • Retrieve a known-working version through your own Steam account
  • Verify the downloaded executable before using it
  • Back up your current executable
  • Install the compatible version
  • Restore the original version whenever you want

How to use it

  1. Download RCT3 Compatibility Helper.
  2. Open the application.
  3. Click Install Compatibility Fix.
  4. A Command Prompt window will appear displaying a Steam QR code.
  5. Scan the code using the Steam mobile app.
  6. Let the helper verify, back up, and install the compatible executable.

That's all she wrote. 🎢

Why does Steam ask me to sign in?

The older RCT3 executable is retrieved directly through Steam using DepotDownloader. The helper does not include or redistribute RCT3 game files.

Steam authentication is handled separately by DepotDownloader. RCT3 Compatibility Helper does not receive or store your Steam username, password, or Steam Guard credentials.

Is this safe?

  • Known SHA-256 hashes are checked before the game is modified.
  • Your current executable is backed up before replacement.
  • Unknown executables are rejected rather than overwritten.
  • Your original executable can be restored from the application.

What problem does this address?

The March 2026 Steam build can launch and play normally, but affected installations may crash when saving a Peep group from the Peep Designer. Testing found that replacing only the affected executable with the verified earlier version restores Peep saving while retaining the current game resources.

For hashes, testing methodology, source code, and the full investigation, see the technical project documentation.
